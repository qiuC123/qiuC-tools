# WeChat OA 项目规则

## Git

- 每个独立的逻辑改动完成后必须立即提交到 Git，不把无关改动混在同一个提交中。
- `main` 只通过 Pull Request 更新；开发改动使用 `codex/*` 功能分支。
- 交付前确认工作区干净，并报告相关提交和远端 CI 结果。

## 测试

- 每次行为、接口、数据模型或构建流程改动，都必须同时新增或更新相关自动化测试。
- 修复缺陷时必须增加能复现该缺陷的回归测试。
- 交付用户前必须运行与改动相关的测试、完整 pytest 和 mypy，并确保全部通过。
- 真实微信、Chrome、账号 API、凭据配置或其他 live smoke 不属于默认测试；只有用户单独明确授权后才能执行。
